AI Job Salary Prediction
Project Description

This project predicts job salaries using machine learning.
It analyzes job-related features such as role, experience, and skills to estimate salary values.

Purpose

Automate salary prediction

Understand factors affecting job salaries

Demonstrate a complete AI / ML workflow

Technologies Used

Python

Pandas, NumPy

Scikit-learn

Matplotlib, Seaborn

Model

Random Forest Regressor

Chosen for handling non-linear data and improving prediction accuracy.

Workflow

Load and clean dataset

Encode categorical features

Split data into training and testing sets

Train Random Forest model

Evaluate using R2 Score and Mean Squared Error

Result

The model successfully predicts salaries with reasonable accuracy based on job features.

Future Improvements

Hyperparameter tuning

Feature selection

Larger dataset
